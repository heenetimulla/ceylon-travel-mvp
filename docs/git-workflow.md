\# Git Workflow - Ceylon Travel



\## Purpose



This project uses Git to track code changes safely and clearly.



Git helps us create checkpoints, work on separate branches, and roll back if something breaks.



\## Main branches



\### master



The original clean Flutter project checkpoint.



This branch should stay stable.



\### devops-CI-foundation



Used to add DevOps-related files such as:



\- GitHub Actions CI workflow

\- CI/CD documentation

\- Git workflow documentation

\- README improvements



\### ceylon-travel-mvp



Used for the main Flutter app development work.



This branch contains the Ceylon Travel MVP screens and features.
